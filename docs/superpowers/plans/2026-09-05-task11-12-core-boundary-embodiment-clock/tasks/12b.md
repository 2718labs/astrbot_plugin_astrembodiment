# 12B Same-Source Release and Package Gate

Owner: release-provenance-owner
Depends on: 12A

## Goal

Prove the closed core surface on real Windows and Linux builds from one clean
source SHA, then assemble the universal package without retired source/modules.

## Context

Read only:

- [retired-surface-release.md](../contracts/retired-surface-release.md)

## Steps

1. Compile and verify the exact public/retired manifest bytes and fixed goldens;
   embed exact source SHA, core API digest, v9 schema digest and vendored tzdb
   release/content SHA in Native build_info and each wheel manifest.
2. Make dirty or mismatched source identity fail before building.
3. Add a reachability-aware package scan for retired exports, imports, commands,
   settings and archive members while allowing private audit codec strings;
   fail on any callable outside the exact 18-method extension allowlist.
4. Prove saved config, ciphertext and DPAPI/key fixtures byte-identical.
5. Build and import the Windows x64 wheel on Windows and Linux x86_64 wheel on
   Linux from the same clean source SHA.
6. Compare imported API/schema/tzdb identities and wheel/binary hashes.
7. Only after both imports pass, assemble the universal ZIP and record the full
   provenance manifest and checksums.

## Acceptance

Run the repository's platform build commands plus:

- python scripts/validate_kit.py
- python scripts/scan_core_boundary.py
- python -m pytest tests/test_release_contracts.py tests/test_static_contracts.py
- git diff --check

Pass requires two real imported wheels, identical source/API/schema/tzdb
identity, manifest-bound wheel and binary hashes, no AstrCyberHuman dependency,
no retired package member, and unchanged protected fixture hashes.

## Return

Return source and commit SHA, platform/runner identities, complete build/import
commands, wheel/binary/ZIP SHA256 values, manifest path, scanner results and all
failed or skipped gates. Report NO_GO until every required real-platform gate
passes.
