## Steps

1. Add all typed contracts, per-kind versions and bounded codecs; preserve
   cross-crate historical kind-8 verification under the controlled exception.
2. Implement Store-owned inbound idempotency before head/event work, persist all
   begin states, and issue Provider authority only on first Claimed commit.
3. Implement delivery idempotency before head/event work, durable inbound
   linkage and current-persona-head binding without a Host base revision.
4. Implement inventory epoch snapshots, get-then-conditional-create persona
   startup, schedule-free profile/schedule CAS, vendored-time validation,
   frozen-time pure status and atomic discriminated one-head/64-receipt clock
   transitions. Forward the exact Due request bytes into advance.
5. Return Store-private exact-scope authoritative heads with Hydrated or
   ReloadRequired; committed hydration failure evicts but never reports failure.
6. Wire Runtime, PyO3, public wrapper and NativeBridge in the same commit.
7. Switch Runtime's semantic begin internals to Store-owned core ingress while
   leaving old Host callers gated until 11C.
8. Consume the already-installed v9 tables exactly; do not CREATE, ALTER or add
   an index/trigger from a request path.
