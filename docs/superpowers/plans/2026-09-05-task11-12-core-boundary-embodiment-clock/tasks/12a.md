## Steps

1. Implement the contract's exact checked-in old name/kind/alias manifests and
   bounded classifier before JSON/event-body decode, Runtime core or DB open.
2. Remove direct Contract, Store, Runtime, PyO3, wrapper, bridge, command and
   callback entry points atomically.
3. Remove Host dynamic _autonomy_call and generic apply_event/alpha3 bypasses.
4. Delete the autonomy supervisor, proactive, proactive_settings and
   secret_store source modules without opening an installed key or config file.
5. Keep ordinary _pending, DeliveryOutcome, Genesis, semantic reservations,
   emotion/personality/matrix and typed inspect/replay.
6. Keep the exact public Rust historical kind-8 DTO/codec exception and fenced
   private legacy migration helpers. Do not expose a Host/Native/Runtime
   submission route or claim that an opaque decoder was implemented.
7. Make reachability checks allowlisted by symbol/codec role, not banned words.
