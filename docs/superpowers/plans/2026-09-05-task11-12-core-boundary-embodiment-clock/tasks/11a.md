## Steps

1. Put the bounded read-only v9 router on the Store::open connection-open path,
   before wall-clock reads, mutating PRAGMA, common metadata, autonomy or
   semantic migration writes.
2. Keep fresh, pre-v8 and exact-v8 paths sequential; finish the combined
   v8/current-semantic state before installing v9 last.
3. Install the entire ordered v9 schema manifest once: boundary, failure proof,
   ingress/delivery, inventory/profile/schedule/clock receipts, every index,
   trigger and already-open-v8 guard. Verify both golden digests.
4. Implement the new verify-only v8 reader, exact raw-cell framing, per-owner
   preimage/disposition chains, group receipts and legacy prefix anchors.
5. Use one outer BEGIN IMMEDIATE and the specified savepoint. Commit only
   applied or typed failed_closed; fully roll back Fatal errors.
6. Add the one centralized typed v9 retired guard and call it as the first
   statement of every temporarily retained executor in autonomy.rs and every
   alpha3 interaction/projection/ecosystem/lived-world path, before body parse,
   target/read, transaction or write.
7. Keep every legacy row, claim, budget, reservation, target/ciphertext and
   operational-authority byte unchanged.
