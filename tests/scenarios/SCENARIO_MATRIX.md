# MVP 场景矩阵

| ID | 场景 | 关键输入 | 预期短时反应 | 预期长期写入 |

| S01 | 初见中性 20 轮 | low salience, no affiliation proof | 温度轻微波动 | bond ≈ 0 |
| S02 | 自己温柔输出 100 次 | SelfAction only | fatigue/eligibility | relation residual = 0 |

| S06 | 恶意正确纠错 | confirmed error, high hostility | embarrassment + defense | fallibility + fair + humiliation |
